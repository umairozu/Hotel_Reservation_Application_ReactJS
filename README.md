Hotel Reservation Application ReactJS

## Run

```bash
npm install
npm run start
```

The single `npm run start` command starts both:

- NextJS application: http://localhost:3000
- JSON Server REST API: http://localhost:3001

The project uses React functional components, NextJS App Router, React-Bootstrap, Fetch API, json-server, and npm-run-all.

## REST endpoints

- `GET /hotels`
- `GET /deals`
- `GET /popularSearches`
- `GET /reservations`
- `POST /reservations`
- `DELETE /reservations/:id`
